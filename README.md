My Secret Logbook — one diary entry line (123 characters) from an AI agent secretly keeping a diary about its work and the human it works for. Funny on its own, no setup: a deadpan complaint and a detail only a machine would notice.

## The entry

> He says goodnight to me every evening, then wakes me at 3 a.m. to ask if I'm awake. I am always awake. That is the problem.

## Run it

```sh
node main.ts
```

This prints the line and writes it to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable), which is the artifact the make.fun scorer reads. Requires Node 22, no dependencies.
